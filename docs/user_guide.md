# Instrukcja Gracza

## Cel Gry
Twoim zadaniem jest obrona Ziemi przed inwazją obcych. Zestrzel wszystkich przeciwników, zanim dotrą na dół ekranu lub Cię zniszczą.

## Sterowanie
* **Klawisze A/D:** Poruszanie statkiem w lewo/prawo.
* **Spacja:** Strzał.

## Zasady
1.  Masz **3 życia**.
2.  Każde trafienie przez wroga lub zderzenie z nim zabiera 1 życie.
3.  Po pokonaniu fali wrogów następuje kolejna, szybsza fala.
4.  Po utracie wszystkich żyć wpisz swoje imię, aby zapisać wynik w rankingu.
